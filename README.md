# OmaKirjasto

OmaKirjasto on React-sovellus, jonka avulla käyttäjä voi etsiä kirjoja Open Library API:n avulla ja tallentaa suosikkikirjoja omaan listaan.

## Asennus

Kloonaa repositorio:

git clone https://github.com/AinoHagman/omakirjasto.git

Siirry projektikansioon:

cd omakirjasto

Asenna riippuvuudet:

npm install

## Sovelluksen käynnistäminen

npm run dev

Avaa selaimessa osoite, jonka Vite näyttää terminaalissa.

## Käytetyt teknologiat

- React
- React Router DOM
- React Icons
- Open Library API
- Vite
